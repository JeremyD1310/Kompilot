# Brouillon — fiche annuaire SaaS

## Description courte
Kompilot est un logiciel SaaS B2B de visibilité locale et de communication multicanale pour PME, commerces, réseaux multi-établissements et agences.

## Description longue
Kompilot aide à préparer des contenus, centraliser des avis et messages, organiser un calendrier de publication et suivre la présence locale et GEO. Les actions sensibles restent soumises à validation humaine. L’offre d’essai dure 14 jours sans carte bancaire.

Fiche non soumise. Vérifier les informations légales, les fonctionnalités disponibles et les conditions de l’annuaire avant toute publication.
