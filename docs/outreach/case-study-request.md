# Brouillon — demande d’étude de cas

Objet : Proposition de documentation d’un bêta-test Kompilot

Bonjour,

Nous souhaitons documenter un éventuel retour d’usage avec votre accord explicite. Aucun nom d’entreprise, outil, chiffre, capture, durée ou résultat ne sera publié sans validation écrite et vérification de la méthode.

Ce brouillon ne doit pas être envoyé ni associé à un bêta-testeur sans validation humaine.
